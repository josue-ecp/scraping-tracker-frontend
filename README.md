# Scraping Tracker - Frontend

Interfaz web desarrollada para monitorear, administrar y visualizar los resultados de procesos de web scraping automatizados.

## 🚀 Tecnologías
* **React.js** / Framework frontend
* **HTML5 / CSS3**
* Conexión con API REST (Backend en PHP)

## 📌 Funcionalidades
* Panel visual para el seguimiento de tareas de extracción de datos.
* Visualización de estados y registros (logs) de scraping.
